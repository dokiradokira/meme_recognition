# 姿势派对

Windows 桌面集成版沿用「从游｜鏡頭放映室」的原窗口，加入五种姿态、骨架和本人定格。[桌面使用与构建说明](desktop/CongYou/README.md)

打开摄像头做一个动作，页面会显示对应的表情包。支持双手举高、双臂横举、左右任一手挥动、双臂交叉和手抵下巴。

## 本地运行

需要 Node.js 22.18 或更新版本，以及 Windows 桌面版 Chrome 或 Edge。

```sh
npm ci
npm run dev
```

打开终端中显示的 localhost 地址，点击「开启摄像头」并授权。请单人正面入镜，让头部、双肩、手肘和手腕都能被看到。做静态动作时保持片刻。挥手时让另一只手自然放低，并用同一只手在肩上方完成一次左右往返。

用任一只手轻抵下巴，保持片刻，即可触发「让我想想」。保持该姿势只触发一次，放下手后可在同一会话再次触发。

识别提示会告诉你何时保持动作、露出关键部位或回到画面。打开「骨架调试」可在本地查看候选动作、缺少的关键点和上次确认中断原因。暂时无法确认动作时，页面保留最近的表情包。

授权后可选择摄像头。切换或关闭摄像头会结束当前会话并清除结果。摄像头断开与画面停滞会分别提示，并提供重试。

「本人定格」默认关闭，开启后，五种动作每次确认都会在结果区临时展示约一秒的本人画面，并使用对应配文。开启系统的减少动态效果后显示静态定格。摄像头预览和动作识别会继续运行，新动作可立即替换定格。

## 构建与验证

```sh
npm test
npm run test:e2e
npm run build
npm run preview
```

开发和构建时会从 Google 下载固定版本的 [Pose Landmarker Lite 模型](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker)，校验 SHA-256，并将模型和 npm 包中的 WASM 放到同源静态目录。随后可使用已缓存的模型。构建产物在 `dist/`，可部署到支持 HTTPS 的静态服务器。生产页面限制网络连接到页面自身的源，摄像头画面和关键点仅用于本地推理。

浏览器测试在 Chrome 和 Edge 中用画布生成可重复的视频流，覆盖摄像头会话、故障恢复、关键点到成品表情包的链路，以及生产构建中的真实 MediaPipe 推理。真实参与者的识别率、误触发率和响应延迟需按[项目方案](PROJECT_PROPOSAL.md#测试与验收)另行验收。

配文、替代文本和来源在 `src/memes.json`，四张原创素材在 `public/memes/`。「让我想想」使用本地 `local-memes/thinking-meme.jpg`，文件存在时自动随本地构建打包。该目录由 Git 忽略。缺少图片时仍会识别并显示动作名与配文。对外分发含该附件的构建前需确认素材授权。

## 真人动作片段回放

仅使用参与者同意用于测试的本地 WebM 录像。每段录像以中性姿态开始和结束，各留约一秒。前三段先做双手举高，接着换为双臂横举，并保持至少一秒。其余片段按表中要求录制。保持单人正面入镜，录制期间不切换设备。

| 文件 | 动作场景 | 预期识别顺序 |
| --- | --- | --- |
| `switch.webm` | 双肘和手腕持续清晰 | 我投降 → 我宣布个事 |
| `brief-occlusion.webm` | 短暂遮住一侧手肘后恢复 | 我投降 → 我宣布个事 |
| `persistent-occlusion.webm` | 从开始横举到恢复中性姿态始终遮住一侧手肘，双肩和手腕保持可见 | 我投降 |
| `natural-out.webm` | 双臂横举时略降手腕、自然弯肘 | 我宣布个事 |
| `wave-fast-left.webm` | 左手较快完成一次往返，另一只手可出框 | 嗨，看到我了吗 |
| `wave-slow-right.webm` | 右手用约一秒完成一次往返 | 嗨，看到我了吗 |
| `crossed-natural.webm` | 自然抱臂，手腕浅过中线，可含轻微遮挡 | 这事我不同意 |
| `similar-negatives.webm` | 斜下伸手、整理袖口、单手搭肩、整理头发、抬手停留 | 无 |
| `chin-left.webm` | 左手抵下巴并保持，然后放下 | 让我想想 |
| `chin-right-switch.webm` | 双手举高、右手抵下巴、双臂横举、再次右手抵下巴 | 我投降 → 让我想想 → 我宣布个事 → 让我想想 |
| `chin-negatives.webm` | 摸鼻子、掩嘴、喝水、整理头发和手短暂经过下巴 | 无 |

给素材目录增加 `timings.json`，以文件名为键，按预期触发顺序填入每次动作完整出现或挥手往返结束的录像时间，单位为秒。负例填空数组。浏览器测试附带 `replay-timing` 记录，将标注时间与页面展示结果时的录像时间对齐。

在 PowerShell 中将环境变量指向存放录像的目录，然后运行回放测试。两款浏览器都使用生产构建和真实 MediaPipe 模型，按顺序核对触发结果及次数。未配置环境变量时，这组测试会跳过。真实设备、识别率、误触发和延迟仍按[发布验收门槛](MVP_V2_ACCEPTANCE.md#p0-用真人回放降低后三种动作的使用门槛)单独测量。

~~~powershell
$env:MEME_REPLAY_DIR = 'D:\path\to\consented-recordings'
npm run test:e2e -- replay.spec.mjs
~~~
