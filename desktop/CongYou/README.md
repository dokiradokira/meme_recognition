# 从游｜鏡頭放映室

在鏡頭前喝一口水，右上角就會播出一支以你為主角的五秒廣告。戴著口罩入鏡再摘下，則會看到自己的戴罩照、「WASTED」和震動彈出的摘罩照。大畫面持續顯示即時影像。

## 開始使用

1. 在 Windows 10（1903 或更新）或 Windows 11 的 x64 電腦上解壓整個資料夾，雙擊 **CongYou.exe**。執行環境為 .NET Framework 4.8。
2. 選擇攝影機，點 **開啟鏡頭**。請一人正面入鏡，讓畫面拍到臉、手和胸前的容器。可以勾選 **靜音**。
3. 從胸前拿起杯子、水瓶或易開罐，自然喝一口，再放下。摘罩效果則從戴著口罩看向鏡頭約一秒開始。如狀態列一直找不到臉，可在即時畫面上拖曳框住從額頭到下巴的整張臉。

攝影機只在點選開啟後啟動。影像在記憶體中短暫保留，程式不輸出錄影檔。兩段配樂由程式合成，只使用影像輸入。

## 姿勢表情包

同一個鏡頭也會辨識雙手舉高、雙臂橫舉、單手揮動、雙臂交叉和單手抵下巴。結果出現在原來的右上放映窗。持續保持只出現一次，放下後可以再次觸發。喝水及摘口罩的原放映優先，放映中略過的表情包在片尾不補播。

按 **F2** 開關即時畫面的骨架，按 **F3** 開關本人定格。也可在底部狀態列按右鍵。兩項預設關閉。本人定格會使用觸發當下的一幀，約一秒後恢復表情包。系統關閉動畫時只顯示靜態定格。

五種姿勢使用 Microsoft Edge WebView2 Runtime 在背景執行隨附的 MediaPipe 模型，全程離線。同一支攝影機由原桌面程式擷取。若姿勢引擎無法開啟，狀態列會提示，原放映功能仍可用。

## 此版如何判定

- **喝水**會追蹤臉的位置，比較下巴附近影像往上移動和嘴部持續被遮住的時間。靠近臉側或把容器放在桌上，不符合嘴部接觸條件。程式根據可見動作推測喝水，無法確認吞嚥，也沒有辨認容器種類的模型。透明瓶、膚色杯子、摸嘴動作與寬杯遮住雙頰都是需要實測的邊界。
- **摘口罩**會保留雙頰與嘴部穩定被遮住時的照片，在同一段臉部追蹤中確認口鼻重新露出後開播，再補取摘罩後的影格。膚色口罩、鬍鬚和強烈側光可能影響判定。追蹤中斷會清空候選照片。
- **放映**使用時間戳回取剛才的鏡頭。喝水廣告先用定格照開場，同時補收後續影格，把同一口播三次。播放中發生的觸發不排隊。

## 現場試播

依次用杯子、瓶子、易開罐各試兩次，每次先把容器放下。再做一次只舉到臉側、一次喝到片尾仍未放下，觀察小窗有沒有多播。摘罩時核對兩張照片的先後，在廣告中途摘一次，確認片尾不補播。已通過合成影格的流程測試；各種實物、臉型與光線的命中率需以現場試播確認。

若無法開啟鏡頭，可先關閉正在使用它的應用程式，在 Windows 相機隱私設定允許桌面應用程式使用相機，再重新開啟程式。

## 從原始碼建置

成品需要 Windows x64、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。解壓全部檔案，再雙擊 `CongYou.exe`。建置另需 Node.js 22.18 或更新版，首次建置會下載固定版本的套件及模型。在 `desktop/CongYou` 用 PowerShell 執行：

```powershell
.\build.ps1
.\build.ps1 -Test -Package
```

第一個指令把可執行程式與相依檔放在 `dist/`。第二個另外執行原版測試及桌面姿勢整合測試，通過後產生 `.build/CongYou-Windows-x64.zip`。測試只枚舉攝影機，使用合成畫面驗證推理。回到倉庫根目錄執行 `npm test` 可驗證共享的五種動作規則及 20 種切換順序。

倉庫根目錄的 `local-memes/thinking-meme.jpg` 存在時會附加到本地成品。缺圖時「讓我想想」仍以字幕呈現。對外分發前請確認圖片授權。

辨識特徵在 `src/Vision.cs`，門檻與狀態轉移在 `src/Gestures.cs`。鏡頭素材生命週期在 `src/Session.cs`，效果分鏡和配樂在 `src/Show.cs`、`src/Audio.cs`。
